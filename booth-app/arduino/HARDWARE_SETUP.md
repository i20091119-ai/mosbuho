# UNO Q 실물 셋업 가이드 (테이블 1세트)

부스 1테이블 기준 전체 결선 + 소프트웨어 올리기 + 점검 순서. **3단계로 나눠** 하나씩 확인하며 진행하세요.

---

## 0. 준비물 체크
- [ ] Arduino **UNO Q** 1
- [ ] **USB‑C PD 멀티허브** (예: Belkin — HDMI + USB‑A×2 + USB‑C(PD 3.0) + 3.5mm, **호스트로 가는 케이블 일체형**)
      · USB‑A가 2개라 **웹캠 + 터치**로 꽉 참(예비 없음). 마우스를 쓸 땐 터치 대신 그 자리에 꽂으면 됨. SD슬롯은 미사용.
- [ ] 포터블 모니터 **프리즘 1530it** (mini‑HDMI, USB‑C×2, 10점 터치)
- [ ] **USB‑C PD 충전기 30W+** (UNO Q 부팅용)
- [ ] **USB‑C 충전기** (모니터 자체 전원용)
- [ ] **USB 웹캠** + 거치대
- [ ] 케이블: **HDMI→mini‑HDMI**, **USB‑A→USB‑C**(터치용)
- [ ] **소형 스피커**(3.5mm)
- [ ] **수동(passive) 부저** 1
- [ ] **불빛 아케이드 버튼** (12V LED + 마이크로스위치)
- [ ] **ULN2003 드라이버 모듈** (28BYJ‑48 키트 동봉품)
- [ ] **12V DC 어댑터** (아케이드 LED 전원) — 0.5~1A
- [ ] 점퍼선 몇 가닥, (있으면) 미니 브레드보드

## 전체 연결도
```
                 ┌──────────── 멀티탭(콘센트) ────────────┐
       [USB-C PD 충전기 30W+]   [USB-C 충전기]   [12V DC 어댑터]
                 │(PD)               │                 │ (+12V / GND)
                 ▼                   ▼                 │
   UNO Q ◄캡티브케이블─[ USB-C PD 허브 ]  1530it USB-C#1 ◄┘(모니터 자체 전원)
   (STM32 헤더)        │  HDMI ─►(HDMI→mini-HDMI)─► 1530it mini-HDMI   [영상]
     │  D2 ─► 부저(+)  │  USB-A①─► USB 웹캠                            [카메라]
     │  GND─► 부저(-)  │  USB-A②─►(USB-A→USB-C)─► 1530it USB-C#2       [10점 터치 또는 마우스]
     │                 │  USB-C(PD 3.0) ◄── PD 충전기                  [UNO Q 전원]
     │                 └  3.5mm ─► 소형 스피커                         [소리]
     │  D3 ◄── 아케이드 버튼 마이크로스위치(NO),  COM ─► GND           [모스 누르기]
     │  D4 ─► ULN2003 IN1 ─(OUT1)─► 아케이드 버튼 LED(-),  LED(+)─►+12V [버튼 불빛]
     └  GND ─┬─ ULN2003 GND ─┬─ 12V 어댑터 GND      ★ GND 모두 공통!
             └───────────────┘
```

## 1단계 · 디스플레이 + 웹캠 + 앱 (전자회로 없이)
> 먼저 "컴퓨터"만 띄워 앱 전체를 시뮬레이션으로 확인.

1. 허브의 **호스트 케이블(일체형 USB‑C)** 을 **UNO Q USB‑C** 에 연결.
2. **PD 충전기 → 허브의 USB‑C(PD 3.0)** 포트. (※ 이게 없으면 UNO Q **부팅 안 됨**)
3. **허브 HDMI → (HDMI→mini‑HDMI) → 1530it mini‑HDMI**.
4. **모니터 USB‑C#1 → USB‑C 충전기** (모니터 자체 전원 ON).
5. **모니터 USB‑C#2 → (USB‑C→USB‑A) → 허브 USB‑A** (터치 **+ 디스플레이 활성화에 필수!**).
   · ★ 이 USB선이 빠지면 mini‑HDMI 꽂아도 **화면이 안 켜짐**("No Signal"). 꼭 연결.
6. **웹캠 → 허브 USB‑A**.
7. **스피커 → 허브 3.5mm**.
8. UNO Q 부팅 → 리눅스 화면이 모니터에 뜨면 OK. 터치가 되는지 화면을 눌러 확인
   (안 되면 허브 USB‑A에 **마우스**로 대체).
9. 소리 출력 장치를 허브로 지정:
   ```bash
   pactl list short sinks
   pactl set-default-sink <허브-USB-오디오-sink>
   ```
10. 앱 실행 → 크롬에서 체험:
    ```bash
    cd booth-app
    python3 -m http.server 8000     # → http://localhost:8000
    ```
    - 학년·이야기·미션·카메라(웹캠 권한 허용)·통계 전부 동작
    - ⑦신호확인·전신키는 **시뮬레이션**(스페이스바/화면 키, 스피커음)

✅ 여기까지 되면 "앱+디스플레이+카메라+소리"는 완성.

---

## 2단계 · 부저(D2) + 아두이노 브리지
> ⑦신호확인에서 **진짜 부저**가 울리게.

1. **수동 부저**: `(+) → D2`, `(−) → GND` (UNO Q Arduino 헤더).
2. `arduino/` 를 **Arduino App Lab** 앱으로 실행
   → `sketch/` 가 MCU(STM32)에, `python/` 이 MPU(Linux)에 배포·구동.
   (Python 브리지가 `localhost:8080`에서 대기)
3. 웹앱 ⑦신호확인 화면 → 우상단이 **"UNO Q 연결됨"** 으로 바뀌면 연동 성공.
4. **신호 재생** → LED(내장)·**부저**가 메시지 모스대로 울림.

✅ 부저가 울리면 출력 연동 완료.

## 3단계 · 아케이드 버튼(D3) + 12V LED(ULN2003·D4)
> 화면 전신키 대신 **불빛 버튼**으로 모스 입력.

### 3‑A. 버튼 스위치 (저전압, 드라이버 불필요)
- 버튼 **마이크로스위치 NO → D3**
- 마이크로스위치 **COM → GND**
- (코드가 `INPUT_PULLUP`이라 누르면 LOW로 읽힘)

### 3‑B. 12V 버튼 LED (ULN2003 경유)
ULN2003 모듈(스텝모터 보드) 사용:
- 모듈 전원: **"+" → +12V**, **"−" → GND**(공통)
- **IN1 → UNO Q D4**
- 버튼 **LED(+) → +12V**
- 버튼 **LED(−) → OUT1** (= 5핀 모터 소켓에서 IN1에 대응하는 출력핀)
  - OUT1 찾기: D4를 HIGH로 두면(코드상 버튼 누름 시) 모듈의 **"A" 표시 LED**가 켜져요.
    그때 LOW가 되는 소켓 핀이 OUT1. (멀티미터로 확인하거나, LED를 한 핀에 꽂고 눌러 테스트)
- ★ **GND 공통**: UNO Q GND ↔ ULN2003 "−" ↔ 12V 어댑터 GND 모두 한 점에 묶기

> **더 간단히(대안)**: 단일 트랜지스터로도 됨 — `D4→1kΩ→2N2222 베이스`, `이미터→GND`,
> `컬렉터→LED(−)`, `LED(+)→+12V`. 핀이 명확(B/C/E)해서 헷갈림이 적어요.

### 동작
- 버튼 누름 → D3 LOW → (브리지) → 브라우저 전신키가 점/대시 판정(타이밍 바·소리 그대로)
- 버튼 LED는 누르는 동안 켜지고, ⑦재생 때 메시지대로 점멸
- 브리지가 없거나 끊겨도 **화면 키/스페이스바로 폴백** → 체험 안 멈춤

## 핀 요약 (UNO Q Arduino 헤더 · 3.3V 로직)
| 핀 | 연결 | 비고 |
|---|---|---|
| **D2** | 부저(+) / GND | 수동 부저, `tone()` |
| **D3** | 버튼 스위치 NO / COM→GND | `INPUT_PULLUP`, 누르면 LOW |
| **D4** | ULN2003 IN1 (→OUT1→12V LED−) | 버튼 LED 점등/점멸 |
| GND | 부저−, ULN2003−, 12V− 공통 | ★ 공통 그라운드 필수 |

> D0·D1(UART)·전원핀은 피하기. 핀 바꾸려면 `sketch/sketch.ino` 상단 상수만 수정.

## 점검 체크리스트
- [ ] PD 충전기 꽂아야 UNO Q 부팅 (안 켜지면 PD부터 확인)
- [ ] 모니터 영상(mini‑HDMI) + 터치(USB‑C#2→허브 USB‑A) + 모니터 자체전원(USB‑C#1)
- [ ] 크롬 기본 오디오 = 허브(스피커 소리)
- [ ] 카메라 권한 허용(localhost라 가능)
- [ ] App Lab 실행 → "UNO Q 연결됨" → 부저 울림
- [ ] 버튼 눌러 모스 입력 / 누를 때 LED 점등
- [ ] GND 3곳(UNO Q·ULN2003·12V) 공통으로 묶였는지 (가장 흔한 실수)

## 자주 막히는 곳
- **안 켜짐** → 허브 PD‑in에 충전기 꽂혔는지(이게 전원).
- **부팅 후 모니터 "No Signal"(보드 LED는 켜짐)** → ★★ **십중팔구 "허브↔모니터 USB 케이블"이 빠진 것.**
  - 실전 결론: **HDMI 뽑았다 꽂기는 아무리 해도 소용없었음.**
    **모니터 USB‑C → 허브 USB‑A 케이블을 연결하니** 그제서야 부팅 시 화면이 떴다.
  - 즉 포터블 모니터(1530it)는 **이 USB 연결이 있어야 디스플레이가 활성화**된다(영상은 HDMI, 활성화는 USB).
  - ✅ 반드시 다 꽂을 것:
    1. 모니터 **전원**(자체 USB‑C 충전기)
    2. 모니터 **mini‑HDMI** ← 허브 HDMI (영상)
    3. **모니터 USB‑C → 허브 USB‑A** ← **이게 빠지면 화면 안 나옴(가장 흔한 함정)**
    4. 허브 **PD 충전기**(UNO Q 전원)
  - (참고) `install-display-service.sh` 는 부팅 시 화면 재인식 보조용 — 위 USB선이 꽂힌 게 전제.
- **소리 HDMI로 감** → `pactl set-default-sink` 로 허브 오디오 지정.
- **터치 안 됨** → 1530it가 "HDMI+USB 터치" 지원해야 함. 안 되면 마우스로(앱은 마우스 100% 동작).
- **버튼 LED 안 켜짐** → GND 공통 안 묶임 / OUT1 핀 잘못 / 12V 전원 미연결.
- **부저 무음** → 능동(active) 부저면 `tone()` 안 맞음 → **수동(passive) 부저** 사용.
