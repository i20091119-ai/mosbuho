# 테스트

## smoke.js — 전체 흐름 헤드리스 스모크 테스트

실제 브라우저 없이 jsdom 으로 앱을 로드해 학년→이야기→미션→팔찌→신호확인→마무리→통계→
전신키 흐름을 클릭으로 검증합니다(25개 체크). 코드 수정 후 흐름이 깨졌는지 빠르게 확인용.

```bash
cd booth-app
npm i -D jsdom      # 최초 1회 (인터넷 필요)
node tests/smoke.js
```

- 종료코드 0 = 전부 통과, 1 = 실패(목록에 ✗ 표시).
- jsdom 은 레이아웃·캔버스·웹캠·오디오를 구현하지 않으므로 **기능/흐름만** 검증합니다.
  실제 화면 렌더링·카메라 인식·소리·전신키 누름 타이밍은 브라우저(또는 UNO Q)에서 확인하세요:
  ```bash
  python3 -m http.server 8000   # → http://localhost:8000
  ```
