# 알고리즘으로 잠그고 수학으로 푸는 비밀 팔찌 — 부스 체험 앱

경상남도교육청 **경남수학문화관**이 **2026 경남직업교육박람회 미래기술 체험존**에서 운영하는
모스부호 기반 phygital(디지털↔실물) 체험 부스 앱입니다. 박람회 종료 후 수학문화관 상설 전시로도
사용하도록 견고하게 설계했습니다.

- **하드웨어**: Arduino UNO Q 1대(테이블당) + 웹캠 + 거치대/조명/라이트박스 + HDMI 모니터
- **단일 정적 웹앱**(GitHub Pages 배포 가능) — UNO Q의 Linux(Chromium)에서 구동
- **핵심 로직(모스·카메라)은 오프라인 동작**, 장식 에셋(폰트·차트)만 CDN

---

## 체험 흐름 (인지 사다리: 추상 → 반실물 → 실물)

| 단계 | 화면 | 내용 |
|---|---|---|
| ② 전신키 | `전신키` | 화면 키를 짧게/길게 눌러 점·대시 생성 (전신 원리 체득) — **추상** |
| ③ 카메라 인식 | `카메라 인식` | 트레이의 빨강·파랑 비즈를 웹캠으로 실시간 해석 — **반실물** |
| ④ 팔찌 제작 | (오프라인) | 확정한 배열대로 끈에 비즈를 꿰어 완성 |
| ⑤ 신호 확인 | `신호 확인` | 완성 메시지를 UNO Q LED·부저로 출력 — **실물** |
| 통계 | `데이터 통계` | 모두가 만든 메시지를 시각화 |

> **비즈 색 규칙**: 짧은 **빨강** 비즈 = 점(·), 긴 **파랑** 비즈 = 대시(—)

## GitHub Pages 배포

1. 이 저장소를 GitHub에 푸시합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`로,
   브랜치를 배포 브랜치, 폴더를 `/booth-app`(또는 루트로 옮긴 경우 `/`)로 지정합니다.
3. 발행된 URL을 부스 모니터의 브라우저에서 전체화면(F11)으로 엽니다.

> 카메라(`getUserMedia`)는 **HTTPS 또는 `localhost`에서만** 동작합니다. GitHub Pages는 HTTPS이므로 OK,
> 로컬 파일(`file://`)에서는 카메라가 막힐 수 있어 아래처럼 로컬 서버로 여는 것을 권장합니다.

## UNO Q에서 실행하는 법

### A) 웹앱만 빠르게 (시뮬레이션 모드)
UNO Q의 Linux 터미널에서:
```bash
cd booth-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (카메라 권한 허용)
```
하드웨어 브리지가 없으면 ⑤단계는 **화면 LED + 부저 시뮬레이션**으로 자동 동작합니다.

### B) 실물 LED·부저 연동 (Arduino App Lab)
`arduino/` 폴더를 Arduino App Lab 앱으로 실행하면 `python/`은 MPU(Linux),
`sketch/`는 MCU(STM32)에 함께 배포됩니다. 자세한 절차는 [`arduino/README.md`](arduino/README.md) 참고.
- Python 브리지 서버가 `http://localhost:8080`에서 대기 → 웹앱이 자동 감지해 **"UNO Q 연결됨"**으로 전환.
- 연결 실패 시 자동으로 시뮬레이션 폴백.

## 조명 보정 사용법 (③ 카메라)

부스 조명/배경이 바뀌면 **30초 재보정**으로 인식 정확도를 회복합니다.

1. `카메라 인식` 화면에서 **카메라 켜기**.
2. 트레이의 **빨강 비즈**를 화면 가운데(점선 영역)에 크게 보이게 두고 **🔴 빨강 보정** 클릭.
3. **파랑 비즈**로 바꿔 두고 **🔵 파랑 보정** 클릭.
4. 보정 상태 메시지에 기준 색상(Hue)이 표시되면 완료.

> 인식은 **색(HSV의 Hue) 기반**입니다. 길이가 아니라 색으로 점/대시를 구분하므로 밝기 변동에 강합니다.
> 채도(S)로 배경을 제거하고 색상(H)으로 빨강/파랑을 판정한 뒤 **좌→우 순서**로 읽어 모스로 변환합니다.
> 라이트박스로 외부광을 차단하고 촬영조명으로 채도를 확보하면 가장 안정적입니다.

## 데이터 통계 / 저장

- 학생이 ②③에서 **신호로 보내기 / 확정**한 메시지를 (개인정보 없이) 수집합니다.
- 기본 저장은 **localStorage**. 상설 운영 시 Google Sheets 등으로 바꿀 수 있도록
  `js/stats.js`의 **저장 어댑터(StorageAdapter)** 만 교체하면 됩니다(주석에 예시 포함).

## 디자인 / 브랜드

- GNMC 로고 기반. 로고 심볼에서 추출한 무지개 팔레트를 디자인 토큰으로 사용
  (빨강 `#C00018`, 주황 `#F07818`, 연두 `#78A818`, 파랑 `#1878C0`, 보라 `#784890` 등).
- **기능색과 장식색 분리**: 점=빨강 / 대시=파랑은 비즈 의미와 일치하는 기능색이므로,
  UI 장식에는 주황·연두·보라를 사용해 혼동을 막았습니다.
- 폰트: Pretendard(한글) + IBM Plex Mono(숫자·모스). CDN 미로드 시 시스템 폰트로 폴백.

> ⚠️ **로고 파일 안내**: 원본 `로고.png`가 프로젝트에 포함되지 않아 `assets/gnmc_logo.svg`로
> 로고 모티프를 **재현**했습니다. 원본을 확보하면 `assets/gnmc_logo.png`로 저장하고
> `index.html`의 `<img src="assets/gnmc_logo.svg">`를 `gnmc_logo.png`로 교체하세요.

## 접근성 / 품질

- 대화면(가로 모니터) 우선, 태블릿 대응 반응형. 큰 글씨·큰 터치 타깃·명확한 대비.
- 키보드(스페이스바)·마우스·터치 모두 지원. `prefers-reduced-motion` 존중.
- 화면 꺼짐 방지(Wake Lock), 3분 무입력 시 홈 복귀(상설 운영 대비).
- 핵심 로직은 외부 라이브러리 없이 순수 JS — 부스 인터넷이 불안정해도 동작.
